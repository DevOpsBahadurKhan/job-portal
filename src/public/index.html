The Job Portal API connects candidates, recruiters and administrators through a focused REST surface. Every response is JSON and protected actions use a JWT bearer token.

Base URLhttp://localhost:5000/api
Content typeapplication/json
AuthJWT in the Authorization header
Public first stepBrowse open jobs without a token

Authentication

Register or log in, then send the returned token with protected requests.

Bearer format: Authorization: Bearer <token>. Roles are CANDIDATE, RECRUITER and ADMIN.
POST/api/auth/registerCreate a candidate account

Passwords must be at least 6 characters. Names must be at least 5 characters.

Body
Field Type Required
name string yes
email email yes
password string yes 
curl -X POST http://localhost:5000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"name":"Aazad","email":"azad@example.com","password":"123456"}'
POST/api/auth/loginGet a JWT token

Returns the authenticated user and a token valid for the configured JWT expiry.

Body
Field Type Required
email email yes
password string yes 
curl -X POST http://localhost:5000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@example.com","password":"admin_password"}'
GET/api/auth/profileJWTRead the current user

Returns the profile identified by the bearer token.

curl http://localhost:5000/api/auth/profile \
  -H "Authorization: Bearer <token>"

Users

User directory access is restricted to authenticated users.

GET/api/usersJWTList all users

Returns the user records available to the authenticated caller.

curl http://localhost:5000/api/users \
  -H "Authorization: Bearer <token>"

Jobs

Browse open jobs publicly. Recruiters manage jobs belonging to their own company.

GET/api/jobsList open jobs

Results are newest first. Page defaults to 1 and limit to 10, capped at 100.

Query parameters
Parameter Description
page Page number
limit Results per page
search Title contains this text
location Location contains this text
jobType FULL_TIME, PART_TIME, INTERNSHIP or CONTRACT
salaryMin Minimum salary threshold 
curl "http://localhost:5000/api/jobs?page=1&limit=10&location=Remote"
POST/api/jobsRECRUITER · JWTCreate a job

The recruiter must own companyId. Status defaults to OPEN.

Body
Field Type Notes
title string Job title
description string Job description
companyId integer Owned company
location string Optional
salaryMin / salaryMax integer Optional
jobType enum FULL_TIME, PART_TIME, INTERNSHIP, CONTRACT
status enum DRAFT, OPEN, CLOSED
skills string Optional 
curl -X POST http://localhost:5000/api/jobs \
  -H "Authorization: Bearer <recruiter-token>" \
  -H "Content-Type: application/json" \
  -d '{"title":"Backend Engineer","description":"Build APIs","companyId":1,"jobType":"FULL_TIME","status":"OPEN"}'
PATCH/api/jobs/:idRECRUITER · OWNER · JWTUpdate a job

Accepts the same job fields as create. The recruiter must be authorized for the job.

curl -X PATCH http://localhost:5000/api/jobs/1 \
  -H "Authorization: Bearer <recruiter-token>" \
  -H "Content-Type: application/json" \
  -d '{"status":"CLOSED"}'
DELETE/api/jobs/:idRECRUITER · OWNER · JWTDelete a job

Deletes the selected job and its related applications.

curl -X DELETE http://localhost:5000/api/jobs/1 \
  -H "Authorization: Bearer <recruiter-token>"

Companies

A recruiter can own one company and create jobs for it.

POST/api/companiesRECRUITER · JWTCreate a company

Creating a second company for the same recruiter returns 409.

Body
Field Type Required
name string yes
description string no
website string no
location string no 
curl -X POST http://localhost:5000/api/companies \
  -H "Authorization: Bearer <recruiter-token>" \
  -H "Content-Type: application/json" \
  -d '{"name":"Acme Labs","location":"Bengaluru","website":"https://acme.test"}'

Applications

Candidates can apply once to an open job.

POST/api/jobs/:jobId/applyCANDIDATE · JWTApply for a job

Applications are rejected when the job is missing, closed, or already applied to.

Body
Field Type Required
coverLetter string no
resumeUrl string no 
curl -X POST http://localhost:5000/api/jobs/1/apply \
  -H "Authorization: Bearer <candidate-token>" \
  -H "Content-Type: application/json" \
  -d '{"coverLetter":"I would love to join your team.","resumeUrl":"https://files.test/resume.pdf"}'

Admin

Administrative operations require an admin JWT. The API can assign candidate or recruiter roles, but never admin.

PATCH/api/admin/users/:userId/roleADMIN · JWTChange a user role
Body
Field Type Allowed values
role enum CANDIDATE or RECRUITER 
curl -X PATCH http://localhost:5000/api/admin/users/2/role \
  -H "Authorization: Bearer <admin-token>" \
  -H "Content-Type: application/json" \
  -d '{"role":"RECRUITER"}'

Models & errors

Successful responses wrap data consistently. List jobs additionally returns pagination metadata.

Success responseCommon shape
{
  "success": true,
  "message": "Operation completed successfully",
  "data": { }
}
{
  "success": true,
  "message": "Jobs fetched successfully",
  "data": [ ],
  "pagination": {"page": 1, "limit": 10, "total": 0, "totalPages": 0, "hasNextPage": false, "hasPreviousPage": false}
}
Error responseValidation and API errors
{
  "success": false,
  "message": "Wrong Credentials",
  "data": null,
  "validation": null
}
Typical status codes
201 Created or successful mutation
200 Successful read/update/delete
400 Invalid request or closed job
401 Missing/invalid credentials
403 Wrong role or ownership
404 Resource not found
409 Duplicate email/application/company
500 Unexpected server/database error
